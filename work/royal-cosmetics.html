THE WORK / 2026

The idea

E-commerce is not only about presenting products beautifully. Shoppers need to find, compare and save items, manage quantities, and understand the next step at checkout.

The approach

I structured the storefront as a React application with reusable components and shared state. Product search, filtering and sorting are connected to cart and wishlist behavior instead of being isolated visual demos.

What I built

A 20-product catalogue, stock-aware quantity handling, persisted cart and wishlist, form validation, route-level views and a simulated order-confirmation journey. Logic tests cover core application behavior.

Portfolio commerce concept. Checkout is simulated; it does not accept real payments or process live orders.

React · TypeScript · React Router · Context API · Vitest
